# Contributing to Panelith

Thanks for your interest. The full guide is in [docs/contributing.md](docs/contributing.md). In short:

- Report bugs and request features with the [issue forms](https://github.com/bharry29/panelith/issues/new/choose); report security problems privately as described in [SECURITY.md](SECURITY.md).
- Panelith is licensed under the [PolyForm Noncommercial License](LICENSE). By contributing, you agree that your contribution may be distributed under it and that Bharath Vadlamannati may also license it to others, including commercially.
- Do not copy code from other panel projects. Describe protocols instead; see [Protocols](docs/protocols.md).
- Build and test with `dotnet test Panelith.slnx` before sending a pull request; see [Building](docs/building.md).
