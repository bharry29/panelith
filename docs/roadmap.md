# Roadmap

Plans, roughly in priority order. Nothing here is promised by a date.

## Panels

- **BeadaPanel driver.** BeadaPanel publishes an SDK and handles sleep and resume well, which makes it the most valuable panel to add.
- **Hardware confirmation** for the Thermalright and Turing panels marked *untested* in [Device support](device-support.md).
- **Turing USB models**, if their obfuscated command packets can be handled cleanly.
- **WeAct Display FS**.

## App

- A certificate from a public authority, so Windows SmartScreen recognises the installer.
- More screens, and a way to import and export screens as single files.
- Per-widget animation and transitions in the designer.
- A Linux tray app on top of the existing command line.
